## 1. 查询「当前行」是否已被笔记锚点涵盖 — 待办

**提出时间**：2026-11-13

**需求**

给定编辑器当前光标所在行，判断这一行是否落在某个锚点的区间内，
并返回/展示覆盖它的锚点（可能多条）。

**动机**

- 避免重复建锚点：同一段代码被不同人反复记笔记
- 快速确认"这里有没有人写过东西"
- 为将来"跳转到当前行已有笔记"提供基础能力

**预期行为（草案）**

| 场景 | 期望 |
|---|---|
| 编辑器 | 光标在已覆盖行时给出提示（状态栏小组件 / gutter 高亮 / 悬浮提示） |
| 快捷键 | 一键跳到覆盖当前行的锚点（面板定位 + 也可以就地展开） |
| API | `GET /anchors/at?file=...&line=N` 返回覆盖该行的锚点列表 |
| 面板 | 「定位到当前行」按钮，按光标行筛选 |

**实现要点（草案）**

- 服务层新增：
  ```kotlin
  fun anchorsAt(file: VirtualFile, line: Int): List<Anchor> =
      anchorsFor(file).filter { line in it.startLine..it.endLine }
  ```
  注意 clone 节点（`mirrorOf != null`）不应参与命中。
- 行号语义：会话内以 `RangeMarker` 的实际位置为准（用户编辑后行号会变），
  跨会话回退到存储的 `startLine..endLine`。
- API 层复用 `/anchors?file=` 的过滤逻辑，新增 `line` 参数即可，避免再加路由。
- 编辑器侧若要实时提示，用 `CaretListener` + 轻量状态栏 widget，
  不要每个 caret move 都重建块。

**风险**

- 行号是"最后已知位置"，代码改动后可能漂移；返回结果需要标注"可能不准"
- 性能：`anchorsAt` 每次 caret 移动都调用 → 需按文件缓存锚点列表（已有 `anchorsFor` 缓存）
