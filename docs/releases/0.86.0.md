# Sidecar Notes 0.86.0

给代码区间挂「侧挂笔记」的 Rider 插件：不改源码，笔记存在项目里的独立 JSON 库中。

## 安装

1. 下载 `RiderNotes-0.86.0.zip`
2. 解压到：
   - Windows: `%APPDATA%\JetBrains\Rider<版本>\plugins\`
   - macOS: `~/Library/Application Support/JetBrains/Rider<版本>/plugins/`
   - Linux: `~/.local/share/JetBrains/Rider<版本>/plugins/`
3. 解压后目录应为 `plugins/RiderNotes/lib/RiderNotes-0.86.0.jar`
4. 重启 Rider，右侧工具窗 **Sidecar Notes**

## 本次更新

- 组的显示/锁定/简洁勾选改为**生效值**：父组隐藏时子组同步显示为未勾选，标题带「（继承）」
- 标签库：**新建标签**按钮移到最前；未分组桶显示为「默认分组」（之前渲染为空）
- 笔记正文支持锚点链接：`[文字](anchor:a_xxx)`，蓝色下划线，点击跳转，悬停变手型
- 面板右键「复制锚点链接」可直接粘贴到任意笔记
- 字体回退：选 JetBrains Mono 时中文不再显示为方块
- 修复原生查询/跳转落到「隐藏笔记之后」的旧位置（小文件不再按视口裁剪块）
- 编辑器右键菜单收敛为一个 **Sidecar Notes ▸** 子菜单，放在最后
- 面板内 F2 / Delete 走独立按键分发，不受键位方案（如 VSCode）影响

## 说明

- 需要 Rider 2026.2（`since-build 262`）
- 本地 HTTP 接口默认关闭，设置里可开启（供脚本 / AI 使用）

完整变更见 [CHANGELOG](https://github.com/Thousandyearsofwar/RiderNotes/blob/main/CHANGELOG.md)。
