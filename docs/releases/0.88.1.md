# Sidecar Notes 0.88.1

给任意代码区间挂「侧挂笔记」的 Rider 插件：**不改源码**，笔记存在项目里的独立 JSON 库中，可随仓库提交、评审、共享。

![编辑器与面板](screenshots/editor-and-panel.png)

## 安装

1. 下载 `RiderNotes-0.88.1.zip`
2. 解压到 Rider 插件目录：
   - Windows: `%APPDATA%\JetBrains\Rider<版本>\plugins\`
   - macOS: `~/Library/Application Support/JetBrains/Rider<版本>/plugins/`
   - Linux: `~/.local/share/JetBrains/Rider<版本>/plugins/`
3. 确认路径是 `plugins/RiderNotes/lib/RiderNotes-0.88.1.jar`
4. 重启 Rider，右侧工具窗 **Sidecar Notes**

要求 Rider **2026.2** 或更新（`since-build 262`）。

## 这一版能做什么

- **代码区间锚点**：一条笔记挂在任意代码片段上；行号变化后自动跟随
- **编辑器内呈现**：gutter 图标、色带、行下摘要块（只显示笔记正文，不占标题）
- **Notes 面板**：分组树、拖拽排序、颜色、多选批量操作、筛选搜索
- **标签库**：分组与颜色，面板可按标签过滤
- **默认分组**：新建笔记自动落进去
- **克隆节点**：同一笔记在列表里多一个节点，编辑器不重复渲染
- **锚点链接**：正文写 `[文字](anchor:a_xxxx)`，蓝色下划线，点击跳转，悬停手型
- **复制锚点链接**：面板右键一键复制，粘到任意笔记
- **导出**：Markdown / PR 评论格式到剪贴板
- **可选本地 HTTP 接口**（默认关闭，仅监听 `127.0.0.1`）：供脚本 / AI 读写，令牌鉴权、增量比对
- **颜色与字体**：8 色调色板；等宽字体缺中文字形时自动回退，不再显示方块
- 中文 / 英文界面

## 本版修复（0.86 → 0.88.1）

- 组的显示 / 锁定 / 简洁勾选改为**生效值**：父组隐藏时子组同步显示未勾选，标题标「（继承）」
- 标签库：新建标签按钮置前；「未分组」桶之前渲染为空白，现显示为「默认分组」
- **跳转到未打开过的代码区域时，摘要块横向偏移很远**：缩进改为按文本列计算，不再依赖视口坐标
- **编辑器字号缩放后对不齐**：缩进存列数、绘制时按当前字体换算
- 去掉内部 API 用法（`PluginManagerCore.getPlugin`），版本号改由构建期资源提供；`verifyPlugin` 通过

完整变更见 [CHANGELOG](https://github.com/Thousandyearsofwar/SidecarNotes/blob/main/CHANGELOG.md)。

## 数据与隐私

笔记保存在项目内的 `.ridenotes/` 目录（JSON）。插件不收集任何数据、不访问网络；本地 HTTP 接口默认关闭，开启后也只绑定 `127.0.0.1`。

## 已知问题

- 从 IDE 书签恢复时，**列表结构**可能与导入前不一致（书签内容、位置、描述均正确），见 [known-issues](https://github.com/Thousandyearsofwar/SidecarNotes/blob/main/docs/known-issues.md)
